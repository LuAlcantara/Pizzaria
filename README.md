# Sistema de Pedidos - Pizzaria

## Sobre o Projeto

O Sistema de Pedidos - Pizzaria é um trabalho acadêmico que implementa uma aplicação web para gerenciar clientes e pedidos de uma pizzaria. Desenvolvido com Java, Spring Boot e Thymeleaf, permite cadastrar clientes, registrar pedidos e listar ambos, com suporte a português e inglês.

### Funcionalidades
- Cadastro e busca de clientes.
- Criação e listagem de pedidos.
- Internacionalização (português e inglês).
- Interface estilizada com CSS.

## Como Executar

### Pré-requisitos
- Java 17+
- Maven
- IDE (ex.: IntelliJ IDEA)

## Tecnologias

- Java 17 e Spring Boot 3: Backend e lógica.
- Thymeleaf: Templates HTML dinâmicos.
- H2 Database: Banco em memória.
- HTML/CSS: Interface e estilização.
- Maven: Gerenciamento de dependências.
